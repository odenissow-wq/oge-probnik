# Пробники по английскому

Пробные экзамены ОГЭ и ЕГЭ по английскому, которые ученики проходят в браузере.

| Страница | Файл |
|---|---|
| Главная со списком вариантов | `index.html` |
| Проверка микрофона | `mic-test.html` |
| ОГЭ, демонстрационный вариант 2027 | `oge/demo-2027.html` |

Новые варианты ОГЭ кладутся в папку `oge/`, варианты ЕГЭ в папку `ege/`, и каждый добавляется ссылкой на главную страницу `index.html`.
